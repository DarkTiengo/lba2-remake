# Citadel vehicle concepts

Visual proposals for approval only. These PNGs are **not** 3D meshes, textures,
or runtime assets; the game does not load them. The B concept was selected for
all three vehicles on 2026-10-02.

| Vehicle | A — faithful modernization | B — functional evolution |
| --- | --- | --- |
| Yellow buggy | `buggy-a-faithful.png` | `buggy-b-evolved.png` |
| Harbour boat | `boat-a-faithful.png` | `boat-b-evolved.png` |
| Blue Rabbibunny scooter | `scooter-a-faithful.png` | `scooter-b-evolved.png` |

The concepts retain the source vehicles' recognizable colors and silhouettes,
with smooth, clean painted metal and restrained realistic detail. The boat's
windows are translucent, with a suggested interior. The scooter is the small
two-seat Citadel vehicle referred to as a motorcycle in the design request.

References used for shape and color: the local game's Citadel harbour view,
the [buggy screenshot](https://www.gameforever.fr/forum/test-little-big-adventure-2-pc-t1265.php),
and the [Citadel scooter screenshot](https://www.pcgamer.com/reinstall-little-big-adventure-2/).
No reference screenshots are included in the deliverable.

First editable B-shape prototypes and previews are in `../vehicles/prototypes/`.
Review their actual 3D silhouettes, materials, and scale before game integration.
